# Вечерний отчёт — Google Apps Script

Скрипт для Google Таблиц: собирает цифры с вкладок мониторинга
(`Сводная`, `Выводы`, `Нагрузка L2`, `Нагрузка L1`, `Нагрузка Fraud`,
`Зависшие тикеты`) в текстовый шаблон и показывает его в диалоговом окне
с кнопкой «Скопировать».

## Установка

### Вариант А — вручную (без установки ничего на компьютер)

1. Откройте вашу таблицу → **Расширения → Apps Script**.
2. Удалите пустой `Code.gs`, который создаётся по умолчанию.
3. Создайте файл `Code.gs` и вставьте содержимое `src/Code.gs`.
4. Создайте HTML-файл `Dialog` (Файл → Создать → HTML) и вставьте
   содержимое `src/Dialog.html`.
5. Сохраните проект и перезагрузите таблицу.
6. В таблице появится меню **«Вечерний отчёт» → «Сформировать отчёт…»**.

### Вариант Б — через clasp

```bash
npm install -g @google/clasp
clasp login
clasp create --type sheets --title "Вечерний отчёт" --rootDir ./src
clasp push
```
Затем откройте таблицу, которую создаст clasp, или привяжите проект к
уже существующей таблице через `clasp clone <scriptId>` с указанием
её Script ID (Расширения → Apps Script → Настройки проекта).

## Как пользоваться

1. Меню **Вечерний отчёт → Сформировать отчёт…**
2. Проверьте поле «Дата (сегодня)» (по умолчанию — сегодня).
3. Заполните поля, которых нет в таблице: ссылку на чат, «Ожидают
   ответа», «Массовый Approved», «Ошибка - Статус», «Проблемные
   области».
4. В разделе «Вторые значения (после «/»)» впишите вручную вторые
   числа для строк API/PSP/BT M/SMP M/L2/L1/L1/Fraud/Зависшие/In
   Progress — таблица даёт только первое число в каждой такой строке,
   второе всегда вводится руками.
5. Нажмите **«Сформировать отчёт»** — текст соберётся в поле снизу.
   Если для какого-то авто-поля в таблице не нашлась строка или ячейка
   на нужную дату оказалась пустой, под текстом появится жёлтое
   предупреждение со списком таких полей — на их месте в тексте будет
   пусто.
6. При необходимости поправьте текст прямо в поле, нажмите
   **«Скопировать»**.

## Как используется дата

Поле «Дата (сегодня)» задаёт ОДНУ дату — саму дату отчёта. От неё
скрипт сам считает нужный столбец в таблице:

- «Создано тикетов (API/BT/PSP/SMP) за прошлый день» — итог за уже
  завершённый день, поэтому берётся из столбца **вчера** (дата минус 1).
- Все остальные автополя (Нагрузка по процессам, L1, Fraud, Зависшие
  (24+), In Progress, BT/SMP Sent/New 72h+) — это снимок текущей
  очереди/нагрузки, поэтому берутся из столбца **сегодня** (сама
  выбранная дата).

Ограничение: если выбрать 1-е число месяца, «вчера» попадёт на
последний день ПРЕДЫДУЩЕГО месяца — а вкладки в этой таблице устроены
по одному месяцу на весь диапазон C:AG. Для 1-го числа поле «Создано
тикетов» скорее всего придёт пустым (с предупреждением) — впишите
его тогда вручную.

## Откуда берётся первое число в каждой строке

Скрипт ищет строки не по фиксированным адресам ячеек, а по тексту
подписи в столбце B — это делает его устойчивым к добавлению строк
выше нужной:

- API (Team A/B) → «Нагрузка L2», строка «Team A»
- PSP, SMP M → «Нагрузка L2», строки «Суммарная нагрузка "PSP"/"SMP M"»
- BT M → «Нагрузка L2», строка «Mena 1x» (под «Суммарная нагрузка "BT M"»)
- L2/L1 (депозиты) → «Нагрузка L2», «L2/L1 Mena 1x» → «Суммарное кол-во Депозиты»
- L1 / Fraud → соответствующий лист, строка «Нагрузка Mena 1x»
- Зависшие PSP/API → «Зависшие тикеты», строка «PSP»
- Зависшие BT M → «Зависшие тикеты», строка «Mena 1x» (под BT M)
- Зависшие SMP M → «Зависшие тикеты», строка «SMP M»
- In Progress (BT/SMP) → «Зависшие тикеты», сумма «PT 24 часа In
  Progress (M)» по Mena 1x и Mena Leads 1x

Полностью автоматические строки (обе части, MENA 1X и Leads 1X, из
таблицы): «BT Sent for processing 72h+» и «BT New request 72h+».
